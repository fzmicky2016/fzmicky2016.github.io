## 使用的工具

- GitHub Desktop：管理文件版本
- GitHub Pages：发布网站
- HTML 和 CSS：制作网页
- GitHub Issues：管理待办任务
- Pull Request：检查并合并修改

## 更新流程

1. 创建 Issue 记录任务
2. 在 GitHub Desktop 中创建分支
3. 修改并检查文件
4. Commit 并 Publish branch
5. 创建 Pull Request
6. 合并到 main
7. GitHub Pages 自动更新网站
